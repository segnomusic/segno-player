## Context

Developers need to select a score view through the custom element, while users need a synchronized built-in control. Automatic mobile adaptation must respond to the actual player container rather than device type or viewport width. The default must remain compatible with the original full-score player.

## Decision

`<segno-player>` exposes `mode="full|two-system|reflow|auto"`, a reflected `mode` property, and a read-only `resolvedMode` property with `auto` excluded. The default is `full`; invalid values use that default. A `modechange` event reports requested and resolved modes whenever either changes.

In `auto`, a `ResizeObserver` resolves to `full` at a host inline size of 768 CSS pixels or larger and to `two-system` below it. Manual modes do not respond to width changes. Reflow is opt-in rather than an automatic result.

The built-in settings contain a native selector for Auto, Full score, Zoom, and Reflow. It writes the public `mode` property and follows external attribute or property changes. The latest user or developer selection wins; the element does not persist preferences. Existing `follow` behavior remains independent and scroll-specific.

## Rationale

One requested-mode field gives external and built-in controls predictable two-way synchronization without hidden precedence rules. A separate resolved mode makes automatic behavior observable. Host-width measurement works in embedded layouts and matches the existing container-based responsiveness. Keeping `full` as the default avoids changing existing consumers and preserves full pages as the canonical representation.

## Consequences

- DL-005 gains the mode properties, attribute, event, and default.
- DL-015 gains container-driven automatic score-view behavior and stable canvas-view parts.
- DL-016 gains the native mode selector in the same responsive settings area as tempo and follow.
- Sites providing slotted controls can use the same public API; preference storage remains application-owned.
- Mode and resolved-mode transitions require browser tests, including changes during playback and asset loading.
