## Context

DL-005 makes `<segno-player>` a framework-free web component. TypeScript already knows the element and its events (`HTMLElementTagNameMap`, `HTMLElementEventMap`), but JSX and framework templates don't know the tag or its attributes. Whether to offer wrapper components for popular frameworks is still undecided.

## Decision

Export `SegnoPlayerAttributes`, the type of the element's attributes, from the package root. Document, in the README, a short type registration for React, Vue and Svelte, and the schema for Angular. Do not ship framework-specific type files, subpath exports or wrapper components, and do not depend on any framework's types.

## Rationale

One exported type is the only piece every framework needs; the registration is a few lines that belong in the user's project. Shipping augmentations of `react`, `vue` or `svelte` would add package exports and tie releases to those frameworks' type changes. The snippets were checked against React 19, Vue 3 and Svelte 5 types.

## Consequences

- Users copy a snippet per framework; the README snippets may need updating when a framework changes how it types custom elements.
- `SegnoPlayerAttributes` must be kept in step with the element's `observedAttributes` and the attribute table.
- Wrapper packages remain possible later and would reuse this type.
